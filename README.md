# KRDict MCP

Remote MCP server for the Korean Standard Dictionary (KRDict).

## Features

- Search Korean vocabulary
- Indonesian translations
- Word details
- Search by definition
- Search by example
- Streamable HTTP MCP transport

## Environment Variables

KRDICT_API_KEY=your_api_key

Optional:

KRDICT_TRANS_LANG=9
PORT=8000

## MCP endpoint

/mcp

## Health check

/health
